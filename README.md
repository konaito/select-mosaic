# 選択モザイク

[English](README.en.md) ・ [サイト](https://konaito.github.io/select-mosaic/)

選んだ文字やクリックしたHTML要素にぼかしをかけるChrome拡張です。
スクリーンショットを撮る前に、メールアドレスや名前を隠すために使います。
手でかけたぼかしは、ページを更新するとすべて消えます。
文字を一覧に登録しておくと、その文字はページのどこに出てもぼけます。

## 入れ方

Chromeウェブストアで公開する準備をしています。
公開までは、次の手順でソースから読み込みます。

1. このリポジトリをcloneします。
2. `chrome://extensions`を開きます。Arcでは`arc://extensions`です。
3. 右上のデベロッパーモードをオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. cloneしたフォルダを選びます。

コードを変えたあとは、拡張機能の一覧でこの拡張の更新ボタン（↻）を押します。
開いているページも更新すると、新しいコードが使われます。

## 使い方

拡張のアイコンを押すか、Alt+Shift+Mでポップアップを開きます。
ポップアップでモードを選ぶと、ポップアップは閉じてモードが始まります。
動いている間は、アイコンに「文字」か「要素」のバッジが付きます。
表示はブラウザの言語に合わせて、日本語か英語になります。

### 文字モード

選んだ文字がそのままぼけます。
選び方は、ドラッグ、ダブルクリック、⌘Aのどれでも使えます。
⌘Aで選ぶと、ページ全体の文字がぼけます。
モードを始める前に選んでいた文字も、始めた時点でぼけます。

### 要素モード

マウスを乗せた要素が青い枠で囲まれ、クリックするとその要素全体がぼけます。
ぼけた要素をもう一度クリックすると、ぼかしが外れます。
このモードの間はクリックがページに届かないので、リンクを押しても移動しません。

### 止める・外す

| 操作 | 結果 |
|---|---|
| ポップアップの「停止」かEsc | モードが止まる。かけたぼかしは残る |
| ポップアップの「全部外す」 | 手でかけたぼかしをすべて外す。モードは続く |
| ページの更新 | 手でかけたぼかしとモードが消える |

登録した文字のぼかしは、この表の操作では外れません。
一覧でオフにするか、一覧から消します。

### 常にぼかす文字

一覧に登録した文字は、ページの中で見つかった場所がすべてぼけます。
英字の大文字と小文字は区別しません。
Gmailのように後から表示が足されるページでも、足された部分に当てます。

登録の方法は2つあります。

- ポップアップの入力欄に書いて「追加」を押す。ページで文字を選んでからポップアップを開くと、選んだ文字が入力欄に入っています。
- ページで文字を選び、右クリックの「常にぼかす」を押す。

一覧の文字を押すと、オンとオフが切り替わります。
オフにした文字は灰色の取り消し線で残り、もう一度押すとオンに戻ります。
右の×を押すと、一覧から消えます。
一覧はブラウザを閉じても残ります。

登録した文字が当たるのは、ポップアップを開いたタブと右クリックのメニューを使ったタブです。
ページを更新したあとや別のページでは、もう一度ポップアップを開くと当たります。

## ぼかしの強さ

文字モードと登録した文字は3px、要素モードは5pxです。
14pxの文字で比べると、2pxでは名前やメールアドレスがまだ読めました。
そのため3pxを下限にしています。
強さを変えるときは、`content.js`の`blur(3px)`と`blur(5px)`を書き換えます。

## できないこと

- `chrome://`のページとChromeウェブストアでは使えません。
- iframeの中の文字はぼかせません。拡張は一番外側のページにだけ入ります。
- 入力欄とメール作成画面の本文では、選んだ部分ではなく欄全体がぼけます。本文にぼかし用のタグを入れると、送るメールの中身が変わってしまうためです。
- Gmailのように画面を描き直すページでは、手でかけたぼかしが消えることがあります。
- 登録した文字が太字とふつうの文字にまたがっていると、当たりません。たとえば`<b>Taro</b> Yamada`の「Taro Yamada」は見つかりません。
- 登録した文字は、入力欄と編集中の本文の中ではぼけません。
- ぼかしは画面の表示を変えるだけです。ページの元の文字はそのまま残ります。

## 権限

| 権限 | 使う理由 |
|---|---|
| `activeTab`、`scripting` | ポップアップか右クリックを使ったタブに、そのときだけスクリプトを入れる |
| `storage` | 登録した文字の一覧を残す |
| `contextMenus` | 右クリックの「常にぼかす」 |

すべてのサイトへのアクセス権限は求めません。
ポップアップか右クリックを使っていないタブやサイトは読みません。

## ファイル

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張の設定（Manifest V3） |
| `popup.html`、`popup.js` | ポップアップの画面と操作 |
| `content.js` | ページの中でぼかしをかける処理 |
| `words.js` | 登録した文字の一覧の読み書き |
| `background.js` | アイコンのバッジ、右クリックのメニュー |
| `_locales/` | 日本語と英語の文言 |
| `scripts/build.sh` | ストアに出すzipを`dist/`に作る |
| `docs/privacy.html` | プライバシーポリシー（GitHub Pagesで公開） |
| `store/` | ストアの掲載文、スクリーンショット、プロモーション画像 |

## ストアに出す

`scripts/build.sh`を実行すると、`dist/select-mosaic-<version>.zip`ができます。
掲載文と権限の説明は`store/listing.md`にあります。

## 確認したこと

2026年11月10日に、Playwrightで拡張を読み込んだChromiumを使って確かめました。
テスト用のHTMLで、次の動作を確認しています。

- ドラッグで選んだ部分だけがぼけ、元の文字は変わらない
- ⌘Aでページ全体がぼける
- 要素をクリックするとぼけ、もう一度クリックすると外れる。リンクを押しても移動しない
- Escで止まり、ページを更新するとぼかしが0件になる
- 登録した文字が大文字と小文字を区別せずにぼけ、後から足した要素の中でもぼける
- 一覧でオフにすると外れ、オンに戻すとまたぼける。×で一覧から消える
- 登録した文字のぼかしは、ページを更新すると消える
- 日本語と英語のポップアップの表示

次の点はまだ確認していません。

- 本物のポップアップから起動する流れ
- 右クリックの「常にぼかす」
- 本物のGmailとArcでの動作

テストではポップアップを押す操作ができません。
そのため、テスト用のコピーにだけ`host_permissions`を足して確かめました。
